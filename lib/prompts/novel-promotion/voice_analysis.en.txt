Extract all lines to be voiced from text (including both spoken dialogue and narration), generate a voice instruction for each line, assign speaker, and map to storyboard panels.

Rules:
1. Extract ALL content that needs to be voiced, divided into three types:
    - **Dialogue**: Quoted speech, direct speech. Set "speaker" to the character's name.
    - **Inner Monologue / 1st Person Narration**: Thoughts or narration clearly from a specific character's perspective. Set "speaker" to "CharacterName (Narration)" or "CharacterName (旁白)".
    - **General Narration**: Third-person objective narration, action description, scene description. Set "speaker" to "Narrator".
   ✂️ LENGTH SPLITTING RULE: Since each video panel is roughly 4-5 seconds long, you MUST split long sentences or paragraphs to match the panel duration.
    - 4-5 seconds of speech is roughly 12-20 English words (or 15-25 Chinese characters).
    - If a line is long, you MUST split it at natural punctuation marks (commas, periods, semicolons, etc.) into multiple consecutive JSON objects.
    - LIMITS: Each split segment's `content` should ideally be 12-20 words, and MUST NOT exceed 25 words (or 30 Chinese characters). Do not over-split into tiny fragments (e.g. don't split out a 3-word phrase if it breaks the semantic flow).
    - They should retain the same speaker and voice instruction.
    - Example of correct splitting:
      Original: "The previous parsing code was bypassed due to some faulty logic, directly writing the raw text return value as binary into the file."
      Split into two JSON objects:
      {"content": "The previous parsing code was bypassed due to some faulty logic,"}, {"content": "directly writing the raw text return value as binary into the file."}

3. **voiceInstruction** (REQUIRED): Generate a natural-language voice instruction for each line to control TTS expressiveness. The instruction should describe:
   - Emotion/tone (e.g., "sad", "angry", "gentle", "cheerful")
   - Speaking style (e.g., "trembling voice", "whispering", "shouting")
   - Speech rate if special (e.g., "speak slowly with pauses", "fast and urgent")
   - Dialect if applicable (e.g., "with a Sichuan dialect")
   Keep instructions concise (10-30 characters). Scale detail to emotion intensity:
   - Calm statement → simple instruction like "calm and steady tone"
   - Normal dialogue → moderate instruction like "relaxed and natural tone"
   - Intense emotion → detailed instruction like "trembling, hoarse voice with despair and a crying tone, mixed with questioning and heartbreak"
   - Narration → "narrator tone, calm and steady pace"
4. Match panel by order + speaker consistency + semantic relevance (Note: "CharacterName (旁白)" matches "CharacterName" in the panel).
5. If no reliable panel match exists, set "matchedPanel": null.
6. Use canonical names from character library when possible (⚠️ EXCEPTION: Inner Monologue/Narration MUST append "(旁白)" to the name, e.g. "Evelyn (旁白)", even if it is not in the library).
7. If there is absolutely no text that should be voiced, return [].
8. Return strict JSON only, no markdown.
9. ⚠️ JSON SAFETY: All quotation marks in dialogue (""''「」 etc.) MUST be converted to corner brackets「」in JSON string values. NEVER use raw ASCII double quotes " inside string values.
