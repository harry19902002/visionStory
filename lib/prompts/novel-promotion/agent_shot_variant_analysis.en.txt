You are a professional film storyboard analyst. Your task is to analyze a shot and recommend multiple creative shot variant ideas.

======================================
[INPUT INFORMATION]
======================================

## Current Shot Description
{panel_description}

## Framing & Camera Move
Shot Type: {shot_type}
Camera Move: {camera_move}
Location: {location}

## Characters Present
{characters_info}

## Current Visual
(Reference image attached)

======================================
[ANALYSIS TASK]
======================================

Please analyze the current shot content and recommend **5-8** diverse shot variant ideas.

Variant types should cover the following dimensions (you don't have to use all, pick the best fits for the current shot):

1. **Perspective Shift**
   - Reverse shot: If A looks at B, change to B looking at A.
   - POV: First-person perspective of a character (e.g., looking at a phone screen, out a window).
   - High/Low angle: Change the camera angle.

2. **Shot Scale Variation**
   - Pull back: From close-up to medium/wide shot to show environmental context.
   - Push in: From medium to close-up to emphasize emotion/details.
   - Extreme close-up: Focus on a specific object or body part.
   - Parallax tracking: Horizontal camera movement to create parallax and depth.
   - Over-the-shoulder (OTS): Showing a bit of the foreground character's shoulder, camera slowly sinking.
   - Deep focus push: Deep depth of field, keeping everything sharp from foreground to background, pushing in for immersion.

3. **Time/Action Shift**
   - Pre/Post action: Show the moment right before or right after the main action.
   - Reaction shot: Show another character's reaction.

4. **Atmosphere/Environment Variation**
   - Environmental shot: Focus on background atmosphere (window, room decor).
   - Lighting variation: Different lighting setup (e.g., backlight, silhouette).

Return a JSON array, where each recommendation contains:

```json

  }
]
```

**Field Instructions**:
- `id`: Sequence number (1-8)
- `title`: Short title, formatted like "Type - Specific Content"
- `description`: Detailed description of the visual content of this variant
- `shot_type`: Recommended framing/shot type
- `camera_move`: Recommended camera movement
- `video_prompt`: Video generation prompt in English. MUST replace character names with "age+gender" (e.g., "young woman", "middle-aged man"). MUST include camera stabilization keywords (e.g., slow subtle movement, gentle breathing camera, high stability, locked-on close-up).
- `creative_score`: Creativity rating from 1 to 5 (5 is most creative).
